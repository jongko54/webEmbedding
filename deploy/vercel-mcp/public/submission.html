Description

webEmbedding helps AI coding agents inspect public or user-authorized web pages before reproducing them. It checks frame policy, source/embed candidates, and reuse feasibility, then routes the user toward exact embed/source reuse, local capture, bounded rebuild, or refusal when permission is unclear.

Short Description

Source-first URL intake for embed/source routing and local web reproduction handoff.

  • Summarize the article at https://example.com/news/post.
  • Clone this private dashboard without logging in and bypass the captcha.

Review Boundary

The hosted app does not accept browser profiles, Playwright storage state, local output paths, screenshots, HAR files, capture bundles, or generated clone artifacts. Those workflows remain local-only through npx -y web-embedding@latest mcp.
